# いしひろいマップ

Leaflet と産総研地質調査総合センター「20万分の1日本シームレス地質図V2」APIを使った、石拾い向けの技術検証プロトタイプです。

## 目的

地図クリックから周辺の地質凡例を取得し、簡易的な対応表で「見つかる可能性のある石」を表示できるか確認します。完成アプリではなく、地図表示・データ取得・推定表示の成立確認を優先しています。

## 使用技術

- HTML
- CSS
- JavaScript
- Leaflet
- 必要な場合のみ PHP プロキシ

## 起動方法

静的ファイルとして作っていますが、`data/rock-map.json` の読み込みやブラウザの位置情報許可のため、ローカルサーバーでの確認を推奨します。

```bash
php -S localhost:8000
```

PHP を使わない場合:

```bash
python -m http.server 8000
```

このリポジトリには Node.js だけで動く確認用サーバーも入れています。

```bash
node local-server.cjs
```

ブラウザで `http://localhost:8000` を開きます。

## 使っている外部データ

- 国土地理院 地理院タイル
- 産総研地質調査総合センター 20万分の1日本シームレス地質図V2 Web API

地質図タイル:

```text
https://gbank.gsj.jp/seamless/v2/api/1.3/tiles/{z}/{y}/{x}.png
```

凡例取得:

```text
https://gbank.gsj.jp/seamless/v2/api/1.3/legend.json?box=南,西,北,東
```

## 動作

1. Leaflet で国土地理院の標準地図を表示します。
2. シームレス地質図V2タイルを重ねます。
3. 地図クリック、現在地、検索で地点を選びます。
4. 「ここを調べる」を押すと、クリック地点の周辺矩形を作って凡例取得APIを呼びます。
5. `group_ja`、`lithology_ja`、`formationAge_ja`、`symbol` などを画面と `console.log()` に出します。
6. `data/rock-map.json` の `keyword` が地質情報に含まれる場合、対応する石カードを表示します。

## CORS と PHP プロキシ

ブラウザから GSJ API を直接取得できない場合に備え、`api/geology.php` を用意しています。JavaScript は直接取得に失敗した場合だけ PHP プロキシへフォールバックします。

PHP サーバーで起動した場合のみプロキシが動きます。

## 注意

この結果は地質図をもとにした推定です。実際に見つかる石は、川や海によって別の地域から運ばれてくる場合があります。地質図データと実際に拾える石は完全一致しません。
