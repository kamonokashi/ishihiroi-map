# いしひろいマップ

Leaflet と産総研地質調査総合センター「20万分の1日本シームレス地質図V2」APIを使った、石拾い向けの技術検証プロトタイプです。

## 目的

地図で選んだ地点の地質凡例を取得し、対応表から「見つかる可能性のある石」を表示します。

## 使用技術

- HTML
- CSS
- JavaScript
- Leaflet
- 必要な場合のみ PHP プロキシ

## 起動方法

`index.html` をダブルクリックしてそのまま開けます。ただし周辺の面積比を測る処理はブラウザの制限で動かないため、ローカルサーバー経由での確認を推奨します。

```bash
php -S localhost:8000
```

PHP を使わない場合:

```bash
python -m http.server 8000
```

このリポジトリには Node.js だけで動く確認用サーバーも入れています。

```bash
node local-server.cjs
```

ブラウザで `http://localhost:8000` を開きます。

## 使っている外部データ

- 国土地理院 地理院タイル
- 産総研地質調査総合センター 20万分の1日本シームレス地質図V2 Web API

地質図タイル:

```text
https://gbank.gsj.jp/seamless/v2/api/1.3/tiles/{z}/{y}/{x}.png
```

凡例取得:

```text
点   : https://gbank.gsj.jp/seamless/v2/api/1.3/legend.json?point=緯度,経度
範囲 : https://gbank.gsj.jp/seamless/v2/api/1.3/legend.json?box=南,西,北,東
全件 : https://gbank.gsj.jp/seamless/v2/api/1.3/legend.json
```

## 動作

1. Leaflet で国土地理院の標準地図を表示します。
2. シームレス地質図V2タイルを重ねます。
3. 地図クリック、現在地、検索で地点を選びます。
4. 「ここを調べる」を押すと、クリック地点そのものの凡例（`?point=`）と、周辺およそ1kmの凡例（`?box=`）を同時に取得します。
5. 凡例の `symbol` から時代のプレフィックスを外した接尾辞で `data/lithology-map.json` を辞書引きし、対応する石を取り出します。
6. 地点の石を主役、周辺の石を控えめに採点して、「よく見つかる／見つかるかも／珍しい」に振り分けます。
7. 石のなかに入っている鉱物も候補として出します。

### 周辺の地質は面積で重みづけします

凡例APIは「その範囲にどの地質があるか」しか返さないため、端をかすめただけの岩体も広大な岩体も同じ扱いになってしまいます。そこで地質図タイルを読み込んで画素の色を数え、それぞれの地質が範囲の何%を占めるかを測っています。凡例の色は2416件すべて一意なので、画素から地質を逆引きできます。

運搬モードでは、あわせて地理院の標高タイルを読み、クリック地点より高い場所を重く数えます。石は上流から流れてくるためです。

### 鉱物は変成帯の名前からも拾います

地質図の岩相名には「ざくろ石帯」「カリ長石菫青石帯」「ローソン石青色片岩亜相」といった変成帯の区分が入っています。これらはその場所に何が結晶しているかを直接示しているので、鉱物の候補として使っています。

### 未固結の堆積地では推定を切り替えます

段丘堆積物・河川堆積物・扇状地などの上に立っている場合、足もとにあるのは固まった岩石ではなく、他所から運ばれてきた石です。この場合は周辺の岩盤を主役に切り替え、さらに川で運ばれるあいだの残りやすさ（チャートは残る、凝灰岩は崩れる）を加味して候補を出します。

### 川原では上流域を割り出します

川原や段丘では、石は上流から流れてきます。周りを四方に均等に見ると、下流側や別の谷の地質まで混ざってしまいます。

そこで標高タイルを読み込み、その地点から標高が下がらない経路でたどり着ける範囲を塗りつぶします。尾根を越えるには一度下る必要があるため、そこで自然に止まり、おおよその上流域になります。多摩川の世田谷付近で約1227km²（実際の多摩川流域は約1240km²）と、実用になる精度が出ています。

上流域が求まったら、その中にある地質だけを運搬元として数えます。地質タブに「上流域の地質」として内訳を表示します。

山間の狭い谷など上流域をうまく捉えられない場所では、次の範囲方式に切り替わります。

### 周辺は段階的に、広い範囲まで見ます

川の石は何十kmも上流から流れてきます。近くに岩盤があるからといってそこで探すのをやめると、実際に落ちている石のごく一部しか出てきません。そこで半径 1km・4km・11km・28km（必要なら 55km）の範囲をすべて重ねて集計し、遠い範囲のものほど「見つかる度」を下げて並べます。

いちばん外側の範囲は取得に10秒以上かかるため、先に結果を表示してから後から候補を追加します。

### 対応表について

`data/lithology-map.json`・`data/legend-index.json`・`data/bundle.js` は生成物です。作り直すときは次を実行します。

```bash
node tools/build-lithology-map.mjs
```

シームレス地質図V2の岩相は610種類あり、そのすべてに石を対応づけています。

対応表には、地質図に描かれない随伴物も含めています。石英脈は幅が数cm〜数m、接触変成帯は幅が数百mしかなく、20万分の1の縮尺では表現できませんが、石拾いでは普通に手に取るためです。

## CORS と PHP プロキシ

ブラウザから GSJ API を直接取得できない場合に備え、`api/geology.php` を用意しています。JavaScript は直接取得に失敗した場合だけ PHP プロキシへフォールバックします。

PHP サーバーで起動した場合のみプロキシが動きます。

## 注意

この結果は地質図をもとにした推定です。実際に見つかる石は、川や海によって別の地域から運ばれてくる場合があります。地質図データと実際に拾える石は完全一致しません。
