# Forest System

Komorebi の森は作業時間に応じてゆっくり成長します。

## 成長ポイント

- 作業 1 分 = 1 成長ポイント
- 成長ポイントは `working` 状態の経過時間に応じて累積されます。

## 成長段階

初期版では次の 8 段階を想定します。

1. 何もない小さな地面
2. 小さな芽
3. 草が増える
4. 若木が生える
5. 木が育つ
6. 花が咲く
7. 小さな森になる
8. 森が豊かになる

## 訪問者

- 作業時間や成長段階に応じて出現候補が増えます。
- 初期版では少なくとも 3 種類の訪問者を想定します。

## ランダムイベント

- 木漏れ日、花びら、光の粒、小動物などの小さな演出を定期的に表示します。
- 短時間に繰り返さないようクールダウンを設けます。
