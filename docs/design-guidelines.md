# Design Guidelines

Komorebi は穏やかで自然な世界観を目指します。

## 色

- 淡い緑、青緑、生成り、薄い黄色、木の色を中心にします。
- 原色やネオンカラーは避けます。

## 余白

- 余白を十分に取り、緩やかな視線の流れをつくります。
- カードやパネルは詰め込みすぎないようにします。

## タイポグラフィ

- OS 標準の日本語フォントを優先します。
- ボタンやラベルは読みやすさを重視します。

## アニメーション

- 草や光の粒など、控えめな動きを取り入れます。
- `prefers-reduced-motion` を尊重します。

## 禁止したい表現

- 派手な点滅や明るすぎるアニメーション
- ゲーム感が強すぎる UI
- 数字や管理画面に偏った見た目
